Veil — документация проекта
===========================

Veil — это современный инструмент для стеганографии и стегоанализа изображений,
разработанный в рамках учебного проекта по информационной безопасности.

Veil демонстрирует:

* реализацию классических и современных алгоритмов стеганографии;
* базовые методы стегоанализа;
* дизайн полноценного Python-пакета;
* CLI-интерфейс, API, модульные тесты и автогенерацию документации.
