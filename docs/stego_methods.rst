Методы стеганографии
====================

Ниже приведён обзор основных стеганографических методов, реализованных в Veil.

LSB (Least Significant Bit)
---------------------------
Изменение младшего бита значений каналов изображения.
Простейший и наиболее распространённый метод стеганографии.

LSB Matching
------------
Младший бит корректируется за счёт увеличения или уменьшения значения пикселя
на 1. Это снижает эффективность простейших атак, рассчитанных на прямые замены.

LSBMR
-----
Использует пару соседних пикселей. Один пиксель кодирует бит через LSB,
второй — через паритет суммы. Это усложняет детектирование по одиночным LSB.

PVD (Pixel Value Differencing)
------------------------------
Количество внедряемых бит определяется разницей яркости соседних пикселей:
чем выше контраст, тем больше бит можно встроить без заметной деградации.

Alpha-LSB
---------
Сокрытие данных в альфа-канале RGBA-изображений. При аккуратном выборе
изображения изменения оказываются слабо заметны.

Border-LSB
----------
Внедрение данных только по границе изображения. Подходит для демонстрации
влияния локального изменения LSB на артефакты и для сравнения с классическим LSB.

DCT (экспериментальный)
-----------------------
Попытка реализации частотного метода: данные внедряются в AC-коэффициенты
дискретного косинусного преобразования. Реализовано в учебных целях и
используется как иллюстрация сложности частотной стеганографии.
